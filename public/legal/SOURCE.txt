# Pomegr corresponding source

Pomegr is free software distributed under the GNU Affero General Public License version 3 only (`AGPL-3.0-only`). The complete corresponding source code for official Pomegr releases is available at no charge from:

https://github.com/Lecarvalho/pomegr

Official release source archives and the Git tag matching each binary version are published with that release. The source includes the build scripts and installation information needed to produce the desktop application. Third-party components remain under their respective licenses, summarized in `THIRD_PARTY_NOTICES.md`.

If the corresponding source for an official binary is unavailable from the release page, contact the maintainer through the repository above and identify the exact Pomegr version shown in the application. No fee is charged for access to the source.
