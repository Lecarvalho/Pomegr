# Pomegr license history

Pomegr, formerly named Threadlight, changed from the MIT License to the GNU Affero General Public License version 3 (`AGPL-3.0-only`) for future development.

## Transition boundary

- Source revisions through and including commit [`95cd66cb60831ef876421a5149d25788f9dab736`](https://github.com/Lecarvalho/threadlight/tree/95cd66cb60831ef876421a5149d25788f9dab736) were published under the MIT License.
- Source revisions beginning with the commit that replaces the repository's root `LICENSE` file with the AGPLv3 text are published under `AGPL-3.0-only`.

The earlier MIT grants remain valid for recipients of those revisions. Relicensing later development does not revoke permissions already granted for earlier source.

The license applicable to a particular revision is the license recorded in that revision's root `LICENSE` file. Dependency and third-party asset licenses remain their respective licenses.

## Why the project changed

AGPLv3 keeps Pomegr genuinely open source while requiring modified network-facing versions to offer their corresponding source code to their users. The change supports an open-source core alongside possible commercial licensing, hosted coordination, enterprise deployment, and support.

The software license does not grant rights to the Pomegr name or visual identity. See [`TRADEMARKS.md`](../TRADEMARKS.md).
