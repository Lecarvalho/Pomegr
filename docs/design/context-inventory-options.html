Session rules

  • Live sessions may reference the current matching provider revision.
  • Completed sessions retain the provider revision they actually matched.
  • If no matching revision exists, render nothing—no instruction to run /context.
  • A real in-session provider snapshot wins over a saved repository diagnostic.

Host boundary: Capture is an explicit native desktop action, never a monitor GET or LAN-triggerable HTTP action. Remote browsers show “Open Pomegr desktop to capture.”
