## Reading Pomegr

Pomegr observes local session records and presents counts, activity, and
explainable signals. It keeps prompts, responses, and credentials out of the
dashboard.

The available information depends on what your coding tool records. A missing
value means Pomegr does not have supported evidence for it. A signal describes
recorded activity or a clearly labeled inference; it does not grade the quality
of the agent's work.
